1. Проект «Конвертер азбуки Морзе»
Краткое описание
Веб-сервис на Go, позволяющий загружать файлы через HTML-форму и автоматически преобразовывать их содержимое между текстом (русский язык) и кодом Морзе. Сервис определяет тип данных (текст или азбука Морзе) и выполняет обратное преобразование, сохраняя результат в локальный файл.

Основной функционал

Загрузка файлов через веб-интерфейс.

Автоматическое распознавание формата входных данных (текст или код Морзе).

Конвертация в противоположный формат с использованием готового пакета morse.

Сохранение результата в файл с именем, сгенерированным на основе временной метки.

Обработка ошибок и логирование с настройкой таймаутов сервера.

Технические детали

Язык: Go, стандартная библиотека (net/http, strings, time).

Структура: пакеты server (настройка HTTP-сервера), handlers (обработчики эндпоинтов / и /upload), service (логика автоопределения).

Сервер запускается на порту 8080 с заданными таймаутами чтения/записи.

Поддерживается кириллица для наглядности.

2. Проект «Тестирование сервера поиска кафе»
Краткое описание
Набор интеграционных тестов для HTTP-сервера, который возвращает список кафе по городу с возможностью фильтрации по количеству и поиску по подстроке. Тесты проверяют корректность работы параметров count и search.

Основной функционал тестов

TestCafeCount – проверяет, что сервер возвращает правильное число кафе при различных значениях count (0, 1, 2, 100), включая граничные случаи, когда запрошено больше, чем есть в городе.

TestCafeSearch – проверяет, что поиск по подстроке (параметр search) возвращает только те кафе, в названии которых содержится искомая строка (без учёта регистра), и что количество результатов соответствует ожидаемому.

Технические детали

Используются пакеты testing, assert и require для проверок.

Тесты используют табличный подход (таблицы с входными данными и ожидаемыми результатами).

Для разделения ответа на отдельные названия применяется strings.Split.

Проверка наличия подстроки выполняется через strings.Contains с приведением к единому регистру.
